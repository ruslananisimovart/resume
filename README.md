# Резюме — Руслан Анисимов, AI Engineer

Сайт-резюме: <https://ruslananisimovart.github.io/resume/>

Статическая страница без сборщика и зависимостей. Один `index.html`, шрифты и медиа лежат рядом — GitHub Pages отдаёт папку как есть.

## Публикация

1. Репозиторий **`resume`** у аккаунта `ruslananisimovart`.
2. Залить содержимое этой папки в корень ветки `main`.
3. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.

Сайт живёт в подпапке домена, а не в корне, поэтому все пути внутри `index.html` относительные, а в `site.webmanifest` `start_url` и `scope` заданы как `./`. Абсолютным остаётся только адрес превью в og-тегах — если репозиторий переименовать, его надо поправить там же.

Первая сборка занимает пару минут. Дальше каждый push публикуется автоматически.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили и скрипты в одном файле |
| `fonts.css` + `fonts/` | Unbounded, Manrope, JetBrains Mono — локально, без обращений к Google Fonts |
| `assets/jelly.mp4` | фоновое видео для верхней частицы (исходное качество) |
| `assets/jelly-lite.mp4` | облегчённая версия для остальных шести частиц |
| `assets/icon-*.png`, `favicon.*` | фавиконы и иконка для «на экран Домой» |
| `site.webmanifest` | имя, цвета и иконки при установке ярлыком |
| `Anisimov-Ruslan-AI-Engineer.pdf` | резюме файлом, кнопка «PDF» в шапке |
| `.nojekyll` | отключает обработку Jekyll — файлы отдаются как есть |

## Что считается на лету

Возраст пересчитывается в браузере посетителя от даты рождения в атрибуте `data-age`. В разметке лежит актуальное значение, поэтому без JS и для поисковых роботов страница остаётся верной.

## Правки

Менять только `index.html` — сборки нет, файл открывается и редактируется напрямую.

Локальный просмотр: открыть папку и запустить любой статический сервер, например `python -m http.server 8080`. Просто двойным кликом по файлу открывать не стоит — на `file://` не сработает загрузка видео и локальных шрифтов.

## Мобильная версия

Отдельного адреса нет — та же ссылка, тот же файл. Вёрстка перестраивается медиазапросами.

Три порога:

- **до 1180px** — прячется шкала глубины;
- **до 900px** — шапка в две строки с прокручиваемым меню разделов, сетки в одну колонку, плитки конвейера в две, таблица «Было → Стало» перестраивается, вода в один слой, часть частиц снимается, видео грузится только облегчённое;
- **до 560px** — плитки конвейера в одну колонку, компактнее отступы и чипы.

Отдельно `@media (hover:none)`: на тач-устройствах наведения нет, поэтому подъём кнопок отключён, а подсветка выбранной стадии не гаснет от касания ряда.
